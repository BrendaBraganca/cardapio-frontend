# Cardápio Digital -Frontend

Este projeto é o desenvolvimento do frontend de uma aplicação que simula um cardápio. A aplicação foi desenvolvida usando **React, Typescript e React Query**.

## 📌 Requisitos
- Node.js
- Npm
- Você pode conferir usando os comandos:
  ```bash
  #Node.js
  node -v
  #npm
  npm --version
  ```

## Instalando o Projeto

```bash
git clone https://github.com/BrendaBraganca/cardapio-frontend
cd cardapio-frontend
```

Instalando as dependências:

```bash
npm install
```

Para rodar a aplicação:

```bash
npm run dev
```

## Compilando

OBS: Lembre-se que o servidor do backend também deve estar em tempo de execução.

```bash
npm run build
```
No seu navegardor digite: http://localhost:numero-da-porta.
